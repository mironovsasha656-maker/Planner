# Planner — Мобильный финансовый планировщик

Приложение для просмотра финансового плана прямо на телефоне. Загружайте Excel-файл и видите красиво оформленные данные о расходах, накоплениях и бюджете. **Работает offline** в метро без интернета.

## Возможности

- 📱 **PWA** — установляется как приложение на телефон
- 🔌 **Offline-first** — работает без интернета, данные в localStorage
- 📊 **Четыре вкладки**: Обзор, Месяц, Категории, Накопления
- 📈 **Интерактивные графики** с кроссхейром для деталей
- 🌙 **Светлая/тёмная тема** — автоматически под систему
- ⚡ **Без внешних зависимостей** — парсит XLSX встроенными API браузера

## Как использовать

1. Откройте приложение в Chrome/Edge на телефоне
2. Нажмите **"Файл"** и загрузите ваш Excel-файл
3. Данные загружаются в память телефона
4. Смотрите графики, расходы, накопления в красивом интерфейсе

## Технологический стек

- **Vanilla JavaScript** (без фреймворков)
- **DecompressionStream** для распаковки XLSX
- **Service Worker** для offline + кеша
- **CSS токены** для светлой/тёмной темы
- **SVG графики** с интерактивностью

## Файлы

- `index.html` — PWA версия со всеми ресурсами
- `sw.js` — Service Worker для offline и кеша
- `manifest.webmanifest` — конфигурация приложения
- `icon-*.png` — иконки 192x512 пикселей (для установки на домэкран)
