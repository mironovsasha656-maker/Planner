# 📱 Финансовый планировщик

🔗 **[Открыть приложение](https://mironovsasha656-maker.github.io/Planner/)**

PWA для отслеживания трат, дневного лимита и накоплений из Excel-файла.

## Возможности
- 📊 Четыре раздела: Обзор, Месяц, Категории, Накопления
- 🌙 Тёмная и светлая тема
- 📱 Работает без интернета (offline-first)
- ⚡ Быстрая загрузка и анимации
